# Scala Conecta

Preciso de um aplicativo parecido com o APP Voluts, onde terei o gerenciamento de escalas para os cultos específicos, e também consigo criar uma escala por departamento, parecido com essa planilha: https://docs.google.com/spreadsheets/d/1_GyNQ5BpsLI6GXsskJVPO32e6MaBlIf4C4mJ4x0vkwE/edit?usp=sharing

Esse aplicativo precisa enviar no início do dia em email para a pessoa escalada dizendo que ela está na escala, com isso, também é preciso uma área de cadastro das pessoas com os campos: nome, departamento, função, telefone e email. Os campos departamento e função podem receber mais de uma opção, visto que temos pessoas que participam de mais de um departamento ou tem mais de um função
